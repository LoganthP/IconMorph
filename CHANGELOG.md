# Changelog

## 0.3.0 (unreleased)
### Added
- **Animated GIF icons on the Windows desktop (opt-in).** In Studio → GIF frame → Frames, turn on *Animate on the desktop* and press Apply. The chosen frame is applied as the normal still icon, every GIF frame is rendered with your design, and the small **iconmorph Live** helper (`iconmorph.exe --live`) plays them over the item's desktop icon at the GIF's own speed. It is click-through, stays on the desktop layer under app windows, follows icons when they move, skips drawing while covered, pauses on lock, and has a notification-area icon (Pause, Open iconmorph, Stop). Optional *Start with Windows* (per-user Run key). It exits by itself when nothing is animating. Restoring, reapplying an older design or applying a still design stops that item's animation. Files are never changed by the helper.
- **My shelf** in the Character Shelf: your own collection. Type or paste any emoji (Win + .), search the emoji list by name, upload several images/GIFs at once, add any character with its hover button, or drag characters onto the *My shelf* cover.

### Changed
- Collections row: visible scrollbar, left/right scroll buttons, and the mouse wheel scrolls it sideways. Scrollbars across the app are easier to see.
- Personal imports limit raised from 60 to 200.

### Limits (honest)
- Animation plays only for items on the desktop itself, not inside Explorer folder windows; macOS and Linux keep the still frame. A GIF with transparent areas shows the still frame behind those areas.
- The helper is the only background process iconmorph ever runs, and only while something is animating.

## 0.2.1 (unreleased)
### Fixed
- **Windows: app shortcuts (Docker Desktop, Jupyter Notebook, Brave, Eclipse, …) could not be chosen.** The standard Open dialog follows a shortcut and hands back the program it launches (`brave.exe`), which Windows cannot give an icon, so the app said "can't be customized here". Choosing a target now uses the Shell's own dialog with `FOS_NODEREFERENCELINKS`, which returns the shortcut itself. If a program is still picked, its shortcut on your Desktop or the Public Desktop is found and used, with a note saying so.

### Added
- **Windows internet shortcuts (`.url`)**: Steam, Epic and web-app desktop icons. Only `IconFile`/`IconIndex` are written; the original file is backed up and restored byte for byte.
- Shortcuts Windows will not let you change (installed for all users on the Public Desktop, or read-only) are flagged before anything is generated, with what to do about it, instead of failing at apply time.

## 0.2.0 (unreleased) — "Little icons. Infinite personalities."
A full UI/UX redesign on top of the unchanged 0.1 engine and transaction model. Existing databases, backups and applied icons carry over (schema v1 → v2 migration is additive and covered by a test).

### Identity
- New brand: **iconmorph.** wordmark and the original "Morphling" mark (a split sage/peach squircle character). App icons regenerated by the engine.
- Warm OKLCH palette and seven themes: Warm Studio, Sakura, Botanical, Coastal, Nordic, Midnight, Monochrome, plus System and a custom accent. Every theme is contrast-checked in CI (text ≥ 7:1, secondary ≥ 4.5:1, accent ≥ 3:1).
- **Chameleon** accents: the accent is derived from the selected character's real colours (engine-side k-means, run once per asset change), kept ≥ 3:1 against the surface; can be switched off to lock the theme.
- Bundled fonts (OFL): Space Grotesk, Manrope, JetBrains Mono.

### Studio
- Canvas-first workspace: zoom around the cursor, pan (wheel / Space / middle drag), checker · dots · paper · dark · tint backgrounds, fit guides, move / scale / rotate handles positioned from the engine's real layout, snapping, full-screen, floating tool dock (Select, Crop, Rotate, Layers, Effects, Reset, undo/redo).
- **Morph Wheel** (M, 1–6): Character, Image, Decorate, Shape, GIF frame, Original folder — radial picker with a keyboard-accessible list equivalent.
- **Character Shelf**: 12 collections + Personal imports, favourites, recents, search, drag-to-canvas, licence info, virtualised grid. New CC0 sets *Pixel Friends* and *Minimalist*.
- Contextual, pinnable/collapsible **Inspector**: textures (dots, stripes, grid, grain), folder styles (classic, rounded, minimal), corner radius and padding for shapes, GIF timeline with frame extraction.
- **Morph Reveal**: slider, side-by-side and toggle comparisons against the plain folder, the applied icon or a pinned design, plus native-size comparison.
- **Native size filmstrip** at 1:1 device pixels with a zoom loupe for every size up to 256.
- Session is saved and offered as "Continue editing" after a restart.
- Responsive layout down to the 980×660 minimum window (condensed top bar, tool options below the canvas, folded shelf on short screens).

### Elsewhere
- **Desktop Theatre**: full-window desktop simulation using your real item names, wallpaper presets or your own image (with colour extraction), before/after, theme previews, icon sizes, shift-select batch hand-off. Clearly labelled as a simulation.
- Asymmetric **Home**, collections-first **Explore** (with a *Your desktop* tab), **Themes** with real-render covers.
- **Time Capsule** (was Restore Centre): per-item timeline of previous designs that can be brought back, multi-select restore, Restore all, and **desktop snapshots** you can return to.
- Motion respects reduced-motion and pauses when the window is hidden. View Transitions are disabled on Linux WebKitGTK, where they crash the web process; a Motion fade is used instead.

### Engine / IPC (additive)
- `preview_icon` now returns the layer layout and accepts custom sizes; new commands `designs_for`, `reapply_design`, `create_snapshot`, `list_snapshots`, `delete_snapshot`, `restore_snapshot`, `source_palette`, `image_thumbnail`.
- Spec fields `folder`, `fill.texture`, `shape.cornerRadius`, `shape.padding` (all optional; 0.1 specs still parse).
- Storage cleanup never deletes icons referenced by a snapshot.

### Performance
- Linux: fixed glibc mmap threshold so freed render buffers go back to the OS. Core RSS after ~40 renders: 318 MB → 144 MB (benchmarks/README.md).
- Workspaces other than Home are code-split and loaded on first use.

## 0.1.0 (unreleased)
### Added
- Rust engine (`iconmorph-core`): safe decoding (PNG, JPEG, WebP, BMP, GIF frames, ICO, ICNS, SVG), four composition modes, shapes, outline/sticker/shadow, multi-size ICO, ICNS with @2x, PNG.
- Native adapters: Windows (desktop.ini, .lnk), macOS (NSWorkspace), Linux KDE (.directory), Linux GIO (metadata::custom-icon), .desktop launchers.
- Transactional apply with backup, verification, rollback, crash recovery journal, history, restore, restore-all, forget, unused-icon cleanup.
- Tauri 2 desktop app: Home, Explore (grid/list, search, filters, virtualised list), Studio (live engine preview, drag/scroll manipulation, native size previews, undo/redo, export), Themes (batch with progress and cancel), Restore Centre (timeline), command palette, light/dark/pastel/high-contrast themes, reduced effects.
- Tests: Rust end-to-end and IPC contract suites, Windows and macOS native integration tests (CI), Vitest UI tests.
