# Code of conduct

IconMorph is a friendly place to build things. We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

- Be kind and assume good intent. Critique code and ideas, not people.
- No harassment, discrimination, sexualised content or personal attacks.
- Help newcomers; there are no stupid questions.

Report problems privately to the maintainers via GitHub. Maintainers may remove content or contributors that break these rules.
